# Preset — grupo com capital para construção

Variação do preset `grupo-em-andamento.md` para quem vai construir: o destaque sai da idade do
grupo e vai para o uso do crédito.
Molde: `../exemplos/34-card-grupo-capital-construcao.tpl.html` (campanha, 4:5, 1080×1350).

| Bloco | Texto |
| --- | --- |
| Rótulo | CONSÓRCIO DE **IMÓVEIS** |
| Título | GRUPO / `{número do grupo}` |
| Selo | CAPITAL PARA / **CONSTRUÇÃO**, com ícone de grua |
| Atributo 1 | GRUPO EM / ANDAMENTO |
| Atributo 2 | PARCELA / REDUZIDA — ícone de cifrão com seta para baixo |
| Atributo 3 | PREFERÊNCIA PARA / LANCE EMBUTIDO |
| Atributo 4 | EXCELENTE / OPORTUNIDADE |
| Frase | CONSTRUINDO O SEU FUTURO, / **PRESERVANDO / O SEU CAIXA.** |
| Linha de crédito (×3) | R$ `{crédito}` · PARCELA DE R$ `{parcela cheia}` · POR APENAS R$ `{parcela reduzida}` / ATÉ A CONTEMPLAÇÃO |

**Foto:** obra — silhueta de prédio em construção ao entardecer. Do acervo do consultor ou gerada,
pela linha "Foto" de `identidade.md`.

**Os dois ícones seguem o texto.** Calendário e troféu, que vêm do preset de grupo em andamento,
não dizem nada sobre construção nem sobre parcela reduzida; viram grua e cifrão com seta.

**Lastro (Regra 7.4):** número do grupo e os três trios de crédito, parcela cheia e parcela
reduzida até a contemplação — todos da administradora, com lastro declarado pelo consultor.
