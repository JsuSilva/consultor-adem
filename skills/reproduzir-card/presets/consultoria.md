# Preset — card de consultoria

Estrutura do card 04, no registro do site (9:16). Molde: `../exemplos/04-card-consultoria.tpl.html`.
Os textos são do serviço do próprio consultor e vêm dele — o molde traz cada um como `[[...]]`.

| Bloco | Texto |
| --- | --- |
| Marca | iniciais · nome · assinatura |
| Prova, no alto à direita | **`{número de prova}`** / `{o que o número prova, em duas linhas}` |
| Rótulo | `{RÓTULO DO SERVIÇO}` |
| Título | **`{palavra em degradê}`** / `{resto do título}` |
| Texto | `{primeiro parágrafo}` / `{segundo parágrafo}`, com **`{trecho em destaque}`** |
| Atributos | quatro pares `{atributo}` · `{apoio}` |
| Linha de método | **`{palavra do método}`** `{resto da linha}` |
| Apoio | `{início}` **`{destaque}`** `{fim}` |
| Botões | `{texto do botão}` (sólido no acento) · telefone do consultor (contorno) |
| Rodapé | nome · assinatura — iniciais · cidade · QR do site |

**Foto:** do acervo do consultor, largura inteira, com véu preto.

**Prova:** número que o consultor consiga demonstrar; trocar o número exige conferir a redação com
ele. **QR do site:** SVG gerado à parte, com o `consultor.site`.
